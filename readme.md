## A Compilation of All Coding Labs and Projects for Econometrics (Knox College Econometrics 303 Coursework)

The repository consists of relevant lab-work through class or personal projects to work with statistical data for causal analysis.

It also contains the Data Source an Econometric Analysis on the Effect of Increasing ICT Access On Labor Outcomes for Women in Nepal, although the nlss living standards survey panel data has been redacted for data integrity and redistribution considerations.
